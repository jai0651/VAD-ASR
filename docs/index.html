A Voice Agent From Scratch

Deep-dive documentation written alongside the code in this repo: every model, every systems decision, and what production stacks do differently — recorded while it was being built, including the failures.

01The pages

1 · Pipeline architecture

The real-time voice loop end to end: the wire protocol, the session state machine, why barge-in dictates the entire threading model, latency budgets, and the orchestration layer nobody's papers talk about.

2 · VAD deep dive

Voice activity detection from your 55k-param conv net to Silero v5. Why VAD and endpointing are different problems, hysteresis, pre-roll, and a real domain-mismatch bug we hit (digital zeros vs. mic noise).

3 · ASR deep dive

From your CTC BiGRU to Whisper: the alignment problem, CTC's blank trick, prefix beam search, encoder-decoder ASR, streaming (RNN-T) vs utterance-based recognition, and why inference engines (CTranslate2) exist.

4 · TTS deep dive

Speech synthesis as ASR's mirror: Tacotron-style attention, the guided attention fix that made our model align, stop tokens, Griffin-Lim phase recovery by hand, and the neural-vocoder revolution up to Kokoro/VITS.

5 · Production inference

What turns models into a service: model loading and sharing, quantization, the event-loop rule, p50/p95 latency, health checks, scaling out, telephony realities (8 kHz, AEC), and what this repo deliberately simplifies.

6 · Decision log (ADRs)

Every significant choice made while building this, with the alternatives considered, the reasoning, and measured evidence — including the failures (MPS 13× slower than CPU here, attention collapse before guided attention).

7 · Noise suppression deep dive

Module 5: a streaming denoiser written by hand from MCRA + decision-directed SNR + log-MMSE/OM-LSA, the two bugs that cost 5 dB of speech, and the measured result that noise suppression helps the VAD at every SNR and hurts Whisper at 0 dB.

8 · State of the art (2026)

What the best open models actually are right now, why those architectures won, the five distinct gaps between these models and production ones (they are not all "data"), open-dataset training recipes that fit on an M4, and where a voice-AI company should actually invest.

10 · The modern recognizer

Module 6: replacing the 2015 ASR with the 2026 one — Conformer with relative-position attention, BPE subwords, hybrid CTC/attention, streaming by dynamic chunk masking, and the full training recipe. Includes the CTC-plateau debugging story and the test that proves the streaming claim.

11 · The neural vocoder

Module 7: predicting phase instead of iterating toward it. A Vocos-style ConvNeXt + exact inverse STFT that removes the one ceiling in this repo no amount of data can lift — why the loss has no phase term, and why the ISTFT must be exact to machine precision.

9 · Beating Smart Turn on telephony

A build plan for an 8 kHz-native end-of-turn detector: the documented, still-open bug that proves the gap is real, the trap that would invalidate the whole claim, the telephony augmentation pipeline, and the benchmark protocol that is the real contribution.

02How to use this repo to learn

  1. Run modules 0–2 (features, VAD, ASR) — each script prints/plots what it learned. Read the source next to its output; every file's docstring is a mini-lecture.
  2. Hear Module 4: scripts/07_vocoder_roundtrip.py (what mels throw away), then scripts/08_train_tts.py and listen to outputs/08_sample_step*.wav go from noise → mumble → speech while 08_alignment.png forms a diagonal.
  3. Run the agent: uv run python -m server.app, open http://127.0.0.1:8000, talk, interrupt it mid-reply.
  4. A/B yourself vs production: same mic audio, swap one engine at a time — VOICE_ASR_ENGINE=whisper, then compare /metrics and transcript quality. The gap you hear is the content of pages 2–4.
The honest answer to "is this how production looks?" The algorithms in modules 0–4 are the real ones — the same math runs inside Silero, Whisper and Kokoro. What production does differently: pretrained weights from enormous data (that's pages 2–4), purpose-built inference runtimes, and a lot of systems engineering around turn-taking and latency (pages 1 and 5 — which this repo does implement for real).
